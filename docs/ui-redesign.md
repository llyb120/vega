# Web 界面重设计说明

本文只描述 `web/` 前端的改版；后端接口、权限和业务行为不变。

## 1. 现状梳理（基于代码）

应用以「数字牛马」为中心，登录后默认进入牛马工作区。

| 区域 | 入口 | 功能 | 权限 |
|---|---|---|---|
| 牛马 · 对话 | 牛马列表 | 与牛马沟通、引用消息、附图、停止本轮；消息里的任务链接跳到任务 | viewer 只读 |
| 牛马 · 任务 | 牛马标签 | 新建任务；按 进行中 / 待我处理 / 已结束 筛选；批准/驳回、补充信息、停止/暂停、继续、重新派发、删除记录；查看执行记录 | viewer 只读 |
| 牛马 · 浏览器 | 牛马标签 | 牛马独立 Chrome：标签页、实时画面（缩放/拖动）、远程操作（点击、滚动、按键、输入、跳转）、停止实例 | 可管理该牛马者 |
| 牛马 · 职责 | 牛马标签 | 职责模板（手动/每日时刻/固定间隔/动态安排），启停、编辑、移除 | 可管理者编辑 |
| 牛马 · 记忆 | 牛马标签 | 新增/编辑/忘记记忆，重要度 | 可管理者编辑 |
| 牛马 · 设置 | 原「⋯」菜单 | 头像（星座/上传）、姓名、工作原则、工作目录、可用密码本条目 | 可管理者 |
| 牛马 · 执行位置 | 原顶部胶囊 | 新任务默认在服务端或某台在线客户端执行 | 可管理者 |
| 牛马 · 删除 | 原「⋯」菜单 | 永久删除牛马 | 可管理者 |
| 创建牛马 | 侧栏按钮 | 名称 + 工作方向；管理员创建团队牛马，其他人创建个人牛马 | 非 viewer |
| 执行记录 | 任务详情 | 只读查看任务主会话 / 浏览器会话 | — |
| 经验图谱 | 侧栏 | 按网站筛选、搜索，查看步骤/前置条件/完成检查/注意事项 | admin |
| 调试会话 | 侧栏 | 按牛马筛选、搜索真实会话，查看整理视图或原始消息 | admin |
| 设置 | 侧栏 | 服务商（含网页登录/读取本机登录/模型发现与编辑/高级参数）、场景模型、技能、MCP（密码本已移到「牛马 · 密码本」，按牛马独立配置） | admin |
| 账号 | 侧栏 | 修改自己的密码；管理员创建账号、改角色、停用/启用、重置密码 | 全部 / admin |
| 登录 | — | 登录；首次使用时用初始化令牌创建管理员 | — |

另有 `view === 'chat'` 的普通会话视图与全局 `BrowserView`：main 上没有任何导航入口（只在 Fire 事件等内部流程中切换），本次保留其代码与样式，不新增入口。远程团队页已删除。

主要问题：
- 桌面端大量留白：任务卡片巨大、设置页单列长滚动、内容最大宽度限制在 1040px，宽屏右侧空着。
- 层级不清：牛马「设置 / 执行位置 / 删除」藏在「⋯」里；「当前工作」侧栏需手动打开。
- 移动端：浏览器页的操作区把画面挤到屏幕下半部分；任务卡片一屏只能看 1 张；本机客户端配对状态只在一个无入口的视图里显示。
- 错误/提示横幅插入页面顶部，挤压内容。

## 2. 新的信息架构

```
侧栏（全局）
├─ 牛马（团队 / 个人分组，状态与待处理数）  ＋ 新建
├─ 管理：经验图谱 · 调试会话 · 系统设置      （admin）
└─ 底部：本机客户端状态 · 账号与安全 · 退出

牛马工作区（顶部：身份 + 状态 + 标签 + 更多）
├─ 对话   —— 宽屏右侧常驻「工作面板」：待你处理（可直接批准/驳回/回复）+ 进行中
├─ 任务   —— 列表 / 详情双栏；窄屏列表 → 详情
├─ 浏览器 —— 画面占满剩余空间；操作工具条只在「操作模式」出现
├─ 职责 · 记忆 —— 紧凑列表 + 内联表单
└─ 设置   —— 由「⋯」提升为标签：资料、头像、密码本授权、危险操作
```

- 「任务链接」从对话跳到任务标签并直接打开该任务详情。
- 系统设置拆分为 服务商 / 场景模型 / 技能 / 密码本 / MCP 五个分区，左侧二级导航（窄屏为横向分段）。
- 调试会话、经验图谱在宽屏为列表 + 详情双栏，窄屏为列表 → 详情。
- 账号页：我的账号 + 成员表格（行内改角色、停用/启用、重置密码）。

## 3. 布局与断点

| 宽度 | 侧栏 | 牛马工作区 |
|---|---|---|
| ≥ 1280 | 248px 完整侧栏 | 对话 + 320px 工作面板常驻（可收起） |
| 1100–1279 | 248px 完整侧栏 | 工作面板改为右侧浮层 |
| 768–1099 | 64px 图标栏（头像/图标，点菜单展开完整侧栏浮层） | 顶栏两行：身份/操作 + 标签 |
| < 768 | 隐藏，左侧抽屉 | 顶部 App 栏（菜单、牛马、更多）+ 标签条；对话页顶部显示「N 项待你处理」入口 |

- 页面内容不再统一限宽 1040px：列表/表格类页面占满可用宽度，阅读类（对话正文）限制行宽约 760px。
- 错误与提示改为右上角（移动端为顶部）浮动通知，不挤压布局；提示 6 秒后自动消失，错误需手动关闭。

## 4. 设计规范

- 颜色：中性灰阶（`--bg / --surface / --surface-2 / --border`）+ 品牌蓝 `--accent`；状态色 info 蓝、warn 琥珀、ok 绿、danger 红，统一用于状态点、徽章和左侧强调条。
- 字号：13px 正文（桌面）、12px 辅助、11px 标签；对话正文 14px；移动端输入框 16px 防止 iOS 缩放。
- 间距：4 / 8 / 12 / 16 / 24；控件高 32px（桌面）/ 40–44px（触屏）。
- 圆角：6 / 8 / 12；阴影只用于浮层（菜单、抽屉、通知）。
- 图标：`Icon.vue` 内置线性 SVG 路径，不引入图标库。

## 5. 关键交互

- 工作面板中的「待你处理」直接调用与任务页相同的批准/驳回/回复操作。
- 任务详情：状态、执行位置、创建时间 → 待处理区 → 最新进展 → 计划清单 → 结果 → 恢复信息 → 执行记录 → 操作按钮。
- 浏览器：查看模式下画面可缩放/拖动；点「开始操作」后才显示滚动、按键、文字输入、网址等工具条（原本始终显示但不可用）。
- 键盘：Enter 发送、Shift+Enter 换行（触屏设备 Enter 换行）；抽屉支持 Esc 关闭与焦点循环。

## 6. 验证方式

- `npm run build:web`、`npm run check` 通过；`npm test` 与 master 结果一致（唯一失败的 Go vendored 摘要用例在 master 上同样失败，与前端无关）。
- 3 个界面源码检查测试（`tests/employee-ui.test.ts`、`tests/local-agent-ui.test.ts`、`tests/settings-refresh.test.ts`）原本按旧文件结构读取 `App.vue` / `EmployeeTaskCard.vue`，已改为读取新组件（`AppSidebar.vue`、`EmployeeTasks.vue`、`TaskDetail.vue`、`WorkPanel.vue`），断言的约束不变。
- 使用 mock 后端（HTTP + WebSocket，数据覆盖各任务状态、对话、职责、记忆、浏览器画面、调试会话、经验、服务商、账号）与 Playwright 在 1440×900、768×1024、375×812 下截图对比，并脚本点击核心流程（导航、抽屉开关与焦点、发消息与引用、工作面板审批、任务跳转与新建、职责/记忆新增、牛马设置保存、执行位置切换、系统设置分区、密码本新增、调试会话双栏、成员重置密码）。
- 另用真实后端（`npm run dev`，本地数据库）验证登录、牛马加载、新建任务、保存牛马设置，以及职责、记忆、设置、系统设置、调试会话、经验图谱页面渲染；该环境未配置模型服务商，发送消息会返回 “Provider not configured”，界面按原逻辑显示错误。
