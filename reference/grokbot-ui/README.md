# 桌面窗口的像素基准

`grokbot-desktop.png` / `grokbot-chat.png` 是桌面客户端要照着做的两张参考图（1040×760，侧栏展开 / 收成图标栏）。
本模型读不了图，下面是把图片逐像素量出来、并写进 `local/ui/style.css` 的数值；改样式时按这张表回归。

2026-11 又用剑来截取**真实运行的 Grok Bot**（1022×726，内容 x=2..1021 / y=1..725）复测：多数尺寸与参考图一致，差异是侧栏宽度（真实 App 默认 279，参考图是拖宽过的 318）、行卡左右内距（16 对 12）、输入条（真实 App 是 42 高、两端全圆的胶囊，参考图是 46 高、圆角 14）、页脚没有单独的蓝色设置圆钮。我们的窗口自带 DWM 边框，所以也不再画参考图里那圈 3px 页面色边。样式以**真实 App** 为准（下表内容坐标 = 真实 App 减去它的 2px/1px 边框）。

| 位置 | 真实 App（内容坐标） | 实现 |
|---|---|---|
| 侧栏 | `#f5f5f5` 0..278（279 宽）+ 1px `#e4e4e4` 分隔线 | `--side-w: 280px`，`.side` 右边框 1px |
| 侧栏顶部两枚按钮 | 白圆 32×32，y=14..45，右距 17、间隔 14 | `.side-top` 高 56 / gap 14 / 右 16 |
| 主头像 | 54×54，y=78..131，侧栏居中 | `.hero` padding-top 22（56+22=78）+ 54 |
| 主名字 | 文字带 y=145..152，12px 浅灰 | `.hero-name` 12px / 行高 16 / gap 9 |
| 列表首行 | 选中卡 `#e4e4e4` 247×54，x=16..262（左右内距 16），y=179..232 | `.rail` 上 23 / 左右 16；`.row` 54 |
| 列表行距 | 行高 54 + 间隔 4（行名带约 58 一行） | `.row` margin-bottom 4 |
| 行内头像 | 36×36，卡内左 6 | `.row` padding-left 6 |
| 行内文字 | 名字 13px、副行 11.5–12px | `.row-text` 13/18 + 12/17，gap 0 |
| 标题胶囊 | 白 39–41 高、top 9，宽随名字，主区居中；内 24 头像 + 13px 名字 | `.pill` 高 39 / top 10 |
| 分享按钮 | 白 34×32，y=14..45 | `.share` |
| 窗口按钮 | 3 枚 45 宽、51 高，右对齐内容右沿；close 悬停 `#eb1e2b`，字形 10×10 | `.win-btn` 45 宽、`.win-btns` 高 51 |
| 会话区 | 气泡左沿 = 主区左 + 16；气泡宽 560 | `.stream` padding-left 16，`.bubble` max-width 560 |
| 气泡 | 字号 15、行高 22、段间距 +10、圆角 16、内距约 6.5/14 | `.bubble` padding 6.5px 14px |
| 输入条 | 胶囊 704×42，主区内距 18/18，底距 17，圆角 21（半高），1px `#c9c9c9` | `.composer` 高 42 / margin 0 18 17 18 / radius 21 |
| 输入条内 | 左 (+) 28 圆钮（内距 7）、右发送 26 圆钮（内距 8） | `.cbtn` 28、`.send` 26，padding 0 8 0 7 |
| 页脚 | 头像 34（x=17..50）、白胶囊 203×36（右距 16）、底距 16；真实 App 没有单独设置钮 | `.foot` 0 16 16 17，`.acc-pill` 36 |
| 收起的图标栏 | 参考图 chat.png：侧栏约 90 宽，只留头像 | `--rail-w: 87px` |

颜色：页面 `#fcfcfc`、侧栏 `#f5f5f5`、选中 `#e4e4e4`、用户气泡 `#7f36cc`、助手气泡 `#f0f0f0`、品牌紫 `#994af3`、发送钮 `#8c43de`。
（真实 App 这次的强调色是绿色，参考图是紫色；按参考图的紫色实现，换主题只改 `--brand` / `--send` / `--mine`。）

参考图的主头像是一只黑色吉祥物（约 54px、带橙色部件），本项目用同一位置画员工自己的 Bot 头像；其余尺寸与颜色都按上表。
