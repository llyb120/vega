# 桌面窗口的像素基准

`grokbot-desktop.png` / `grokbot-chat.png` 是桌面客户端要照着做的两张参考图（1040×760，侧栏展开 / 收成图标栏）。
本模型读不了图，下面是把两张图逐像素量出来、并写进 `local/ui/style.css` 的数值；改样式时按这张表回归。

| 位置 | 参考值（1040×760） | 实现 |
|---|---|---|
| 外侧留边 | 页面色 `#fcfcfc` 占 x=0..2（四边同） | `body { padding: 3px }` |
| 侧栏 | `#f5f5f5` x=3..320（318 宽） | `--side-w: 318px` |
| 收起的图标栏 | `#f5f5f5` x=3..89（86 宽），头像 36 居中 | `--rail-w: 86px` |
| 侧栏顶部两枚按钮 | 白圆 32×32，x=225..256 / 271..302（间隔 14，右距 17），y=14..46 | `.side-top` 高 56、gap 14、右 17 |
| 主头像 | 54×54，x=135..188，y=79..132 | `.hero` padding-top 20（56+20=79） |
| 主名字 | 文字带 y≈146..153，12px 浅灰 | `.hero-name` 12px / 行高 16 / `--faint` |
| 列表首行 | 选中卡 `#e4e4e4` 294×54，x=15..308，y=180..233 | `.row` 54 高，`.rail` 上 21 / 左右 12 |
| 列表行距 | 行高 54 + 间隔 6 | `.row` margin-bottom 6 |
| 行内头像 | 36×36，卡内左 6 | `.row` padding-left 6 |
| 行内文字 | 名字带 195..205、副行 211..224 | 名字 13px/18、副行 12px/17，gap 0 |
| 标题胶囊 | 白 85×39，x=638..722，y=10..49；内 24 头像 + 13px 名字，左 7 右 14 间隔 12 | `.pill` |
| 分享按钮 | 白 34×32，x=856..889，y=15..46 | `.share` |
| 窗口按钮 | 3 枚 45 宽、字形 10×10（min 线 1px、max 方框、close X），字形 y=21..30 | `.win-btn` 45 宽、`.win-btns` 高 51、图标 10px/1px 描边 |
| 页脚 | 头像 36（x=18..53）、白胶囊 196×29（x=64..259）、蓝钮 36（x=270..305），底距 14 | `.foot` 左右 15、底 14 |
| 会话区左沿 | 气泡左沿 x=339 | `.stream` padding-left 18（3+318+18） |
| 会话区右沿 | 用户气泡右沿 x=1025，无可见滚动条 | `.stream` padding-right 12，隐藏滚动条 |
| 气泡 | 圆角 16、单行 35 高、字号 15、行高 22、段间距 +10、max-width 550 | `.bubble` padding 6.5/14 |
| 气泡间隔 | 8px | `.msg` margin-bottom 8 |
| 输入条 | 白条 682×43，x=339..1021，y=700..743，圆角 14，1px `#cdcdcd` 边 | `.composer` 高 43、margin 0 16 14 18 |
| 输入条内 | (+) 26 圆钮 x=347..373；右侧浅圆钮 26（x=955..980）+ 紫色发送 26（x=991..1016） | `.cbtn`/`.send` 26，左右内距 8/5 |

颜色：页面 `#fcfcfc`、侧栏 `#f5f5f5`、选中 `#e4e4e4`、用户气泡 `#7f36cc`、助手气泡 `#f0f0f0`、品牌紫 `#994af3`、发送钮 `#8c43de`、底部蓝钮 `#3278ed`。
参考图的主头像是一只黑色吉祥物（约 54px、带橙色部件），本项目用同一位置画员工自己的 Bot 头像；其余尺寸与颜色都按上表。
